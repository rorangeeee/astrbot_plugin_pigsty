## 基本功能
**基本命令**：通过`pig`命令触发help面板。

**添加小猪**：`pig add [昵称]` 添加一只单独的小猪到你的猪圈，`pig add @用户 [昵称]` 添加一只与群友绑定的小猪到你的猪圈。

**重命名**：对小猪名字不满意？通过`pig rename [小猪序号（通过pig show查看）] [新名字]`对小猪使用命名牌。

**猪圈状态查看**：`pig show`展示你猪圈里的小猪。

**事件推送绑定**：新小猪自动绑定添加时所在的群聊或私聊。使用 `pig bind <序号>` 将一只小猪的事件推送绑定到当前会话，`pig bind all` 将自己当前猪圈中的全部小猪绑定到当前会话；也可在其他群聊或私聊中执行以换绑。`global` 模式下猪圈数据共享，每只小猪的推送位置单独保存。`group` 模式下命令只操作当前会话对应的猪圈。

已有小猪没有绑定时不推送事件，事件仍会记录到日记，可通过 `pig diary` 查看。`pig show` 只对未绑定的小猪标注“未绑定”。查看、改名和互动不会改变绑定。

**放生**：通过`pig letgo [小猪序号/名字]`把小猪放生。放心，小猪会继续快乐地度过它的一生。

## 小猪数值
**体重**：刚出生时默认5KG左右。*尼德小猪真是肥嘟嘟的。*

**健康**：小猪健康值，默认100。健康度降至0时小猪死亡并从猪圈中移除。

**心情**：每天随机波动。对小猪好点可以让小猪开开心心哒。

**体力**：小猪的活力值，也会随机波动。不知道有什么用，先加在这吧。

## 事件
目前有三类事件可触发：成长事件、突发事件、交互事件。

### 成长事件
每天北京时间9:00，小猪会进行每天的成长。各项数值都可能会有增减。

### 突发事件
概率触发，具体发生啥我也不知道（？）。
单个小猪长时间不发生突发事件的话，会提高突发事件发生概率。
若发生了突发事件，会在当天向小猪绑定的会话推送。发送前换绑，尚未发出的通知会发送到新绑定的会话。

### 交互事件
通过自然语言告诉bot你想对某只小猪做啥。然后看看结果如何。
需要大模型驱动。建议使用响应速度、推理速度快的模型，保证体验。

## 配置项
**管理员**：`pig status`命令仅管理员可触发。除此之外不知道有什么用。

**作用域**：`global`全局作用，`group`按群聊隔离。

**模型配置**：可以指定本插件进行LLM交互（突发事件、交互事件）时使用的大模型。需要先在astrbot面板配置好提供商，再从配置好的提供商/模型中选择。**建议使用响应速度快、推理速度快的模型，使用体验更好。**
